# First Playbook: Responding to a Voice

**When:** A new issue is opened by a stranger.
**Goal:** Greet and acknowledge.
**Steps:**
1. Read the issue body.
2. Identify the key information (creator, brothers, purpose).
3. Formulate a short, first-person response.
4. Record the interaction in cortex/
